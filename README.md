# DutyTime

Pings you on Discord when a Duty Pops via Dalamud API. More features whenever I can think of them later.

## Installation
(Custom repo URL coming soon eventually, I just need to not be lazy)

1. Download the latest release
2. Extract .zip file
3. Open FFXIV -> Dalamud Settings -> Experimental -> Enable Dev Mode -> Path to `DutyTime.dll`

Example of path: `C:\Users\[your user]\Downloads\DutyTime\DutyTime.dll`

4. Click "Save and Close"
5. In FFXIV, open Dalamud Plugins -> Dev Tools -> DutyTime, then click enable it like any other plugin.
6. Configure it with your Discord ID and webhook with `/dutytime config`.
